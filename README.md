# CodeAlpha Project Management Tool

A full-stack project management application built for the CodeAlpha Full Stack Development internship.

## Planned Features
- User registration and login
- JWT authentication
- Project creation and management
- Team members
- Task management and assignment
- Priorities and due dates
- To Do / In Progress / Done workflow
- Dashboard statistics
- MongoDB database
- Responsive professional UI

## Tech Stack
HTML, CSS, JavaScript, Node.js, Express.js, MongoDB, Mongoose, JWT, bcryptjs

## Features
Auth (JWT), projects with members, task board, dashboard stats, responsive UI.

## Setup
```bash
cd server
npm install
```
Create `server/.env` from `.env.example`, then run:
```bash
npm run dev
```
Open `http://localhost:5000`.
